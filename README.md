# IRCTC Sprint — Design Engineering & AI Feature Sprint

## Overview

This repository contains Part A of the IRCTC Design Engineering Sprint assignment.

The objective of this sprint is to study real-world UX, performance, and system design problems inside the live IRCTC platform and document them with detailed user flows, affected users, frequency analysis, and failure points.

This project focuses on identifying critical pain points faced by Indian railway passengers during:

- Tatkal booking
- Train search
- Seat selection
- PNR enquiry
- Reservation chart viewing
- Login/session handling
